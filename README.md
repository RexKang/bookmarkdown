# BookmarkDown

本地优先的视频收藏「海报墙」——Chrome 扩展（Manifest V3）。

看到喜欢的视频，右键一键收藏；每条收藏都写进**你自己磁盘上的 Markdown 文件**，封面存为本地图片快照（WebP 或原图）。数据可直接用 Obsidian 打开、用 git 版本管理，不依赖任何云服务、数据库或账号。

[English README →](README.en.md)

## 特性（v0.3.1）

- **一键收藏**：任意网页右键「收藏到 BookmarkDown」；也支持右键图片 / 右键链接
- **元数据抓取**：B 站 / YouTube 深度适配（标题、UP 主、时长），其他网站走 og 标签通用兜底
- **封面双通道**：优先页面内直接获取；失败自动截取可见区域兜底；原图 ≤1080P 原样保留、超限缩至长边 1920（WebP q92）——清晰度优先
- **零 host_permissions**：安装时没有任何权限警告；仅在收藏的一瞬间通过 activeTab 向当前页面借一次临时授权
- **海报墙**：左栏导航（墙 / 默认 / 合集 / 设置），网格 / 列表双视图，搜索、状态筛选、合集归类；浅色 / 深色双主题一键切换
- **私密合集**：合集可设为「私密」，其条目不在「墙」展示；侧栏与合集卡显示 🔒
- **批量管理与编辑**：「批量管理」进入批次模式（删除 / 设置作者 / 复制至 / 移动至）；详情卡 →「编辑」可改标题 / 链接 / 作者 / 状态 / 归属合集 / 标签 / 笔记 / 封面
- **标签与笔记**：编辑界面可打标签、写正文笔记；详情卡内笔记按 Markdown 富渲染（GFM）；标签筛选自动汇集全库
- **补抓封面**：老条目点「补抓封面」，按站点一键授权后自动抓取 og 标题与封面补齐（安装仍无任何权限警告）
- **popup 快搜**：点扩展图标即搜（标题 / 作者 / 标签 / 链接），回车直达全页墙
- **Side Panel**：边看视频边翻库的窄栏单列视图
- **键盘导航**：`/` 或 `Ctrl+K` 聚焦搜索；方向键移动卡片焦点；`Enter` 打开详情
- **B 站收藏夹批量导入**：设置页一键读取你的 B 站收藏夹，批量入库（自动抓封面 / 去重 / 标题净化）
- **失效链接检测**：批量「检测失效」→ 404 / 拒连标红「已失效」，403 / 限流标「存疑」；结果写回条目并在卡片上显示
- **导出静态 HTML**：一键生成 `wall.html`（自带搜索过滤，默认不含私密合集），脱离扩展直接用浏览器浏览
- **多库**：设置页维护多个库目录，一键切换；「添加库目录」即纳入列表（移除只出列、不删文件）
- **合集层级**：合集可设为子合集（侧栏缩进显示）；合集管理「调整层级」；删合集时其子级自动提升到顶层
- **详情卡**：点条目查看详情；点封面全屏看图（点击任意处 / Esc 返回）
- **手动添加**：抓不到的内容（App 里看到的、canvas、受限页面）用「＋ 添加收藏」手动补录；封面支持 点击选择 / 拖入 / 任意处 Ctrl+V 粘贴
- **去重**：同一视频 / 链接重复收藏会被识别（已有条目可补封面升级）

## 库结构

选一个文件夹作为「库」，**建议 git init 并定期提交**——这就是你的收藏备份方案：

```
库/
├── index.md            # 合集清单（含「默认」容器登记）
├── 默认.md             # 默认容器：新收藏先落这里
├── 硬件.md             # 每个合集 = 一个 Markdown 文件
├── thumbnails/
│   └── BV1zmYP6aEdH.webp
└── settings.json       # 排除规则
```

每条收藏是 Markdown 里的一个区块：隐藏 JSON（元数据）+ 小节正文，对 Obsidian 与 git diff 都友好：

```markdown
<!-- bookmarkdown-entry {"key":"vid:BV1zmYP6aEdH","title":"…","url":"https://www.bilibili.com/video/BV1zmYP6aEdH/","platform":"bilibili","author":"…","duration":713,"thumbnail":"thumbnails/BV1zmYP6aEdH.webp","status":"想看","collected":"2026-10-01 19:02"} -->
## （标题）

- URL: https://www.bilibili.com/video/BV1zmYP6aEdH/
- 平台: bilibili
- 作者: …
- 时长: 713 秒
- 状态: 想看
- 收藏于: 2026-10-01 19:02

![封面](thumbnails/BV1zmYP6aEdH.webp)
<!-- /bookmarkdown-entry -->
```

## 安装（开发版）

尚未上架应用商店，以开发者模式加载：

1. clone / 下载本仓库
2. 打开 `chrome://extensions`，开启右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择仓库根目录（含 `manifest.json` 的那一层）
4. 点扩展图标 →「打开库」→ 选择一个文件夹作为库目录

> 浏览器重启后需在库页点一次「解锁库」重新授权；授权弹窗里选「每次访问都允许」可减少后续提示。

要求：Chrome / Edge（Chromium 内核）≥ 122。

## 使用

- **收藏**：视频页 / 任意网页右键 →「收藏到 BookmarkDown」，扩展图标出现 ✓ 徽标即成功
- **整理**：「批量管理」→ 勾选条目 → 删除 / 设置作者 / 复制至 / 移动至；详情卡 →「编辑」改单条全部字段；点封面 → 全屏看图
- **补票**：「＋ 添加收藏」手动补录（在合集内打开则保存进当前合集；封面可直接 Ctrl+V 粘贴）
- **补抓**：无封面老条目 → 详情卡 →「补抓封面」→ 浏览器弹出该站点授权 → 自动补齐封面与标题
- **快捷**：`/` 聚焦搜索 · `Esc` 清搜索 / 关弹窗 · 方向键走卡片 · `Enter` 开详情
- **B 站导入**：设置 →「读取我的收藏夹」→ 选收藏夹 →「开始导入」（需已登录 B 站；导入会新建「B站·××」合集）
- **失效检测**：批量管理 → 选中条目 →「检测失效」；红色徽章 = 已失效
- **静态导出**：设置 →「导出 wall.html」→ 用浏览器打开库目录里的 `wall.html`
- **多库**：设置 →「多库」行点名称切换；「添加库目录…」把新目录加入列表
- **层级**：合集管理 → 选中合集 →「调整层级 ▾」→ 设为某合集子级 / 移到顶层
- **排除规则**：不想被收藏的站点，编辑库里的 `settings.json`

## 开发与测试

无构建步骤、无运行时依赖，源码即产物（原生 ES Modules）：

```bash
node test/md.test.mjs   # 文本层：条目 / 合集解析、增删改
node test/fs.test.mjs   # 存储层：库初始化、去重、目标合集写入（内存假目录）
```

## 隐私

- 数据只写进你选择的本地文件夹；扩展不发起任何上传，无遥测、无账号
- 无 host_permissions：仅在你右键收藏 / 点击图标时，借 activeTab 临时授权访问当前标签页
- 封面获取在页面上下文内完成，不经过第三方服务
